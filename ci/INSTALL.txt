TouchCursor 1.7.1 (Rev 10) + Punto Switcher compatibility fix
==============================================================

Change: keystrokes generated by other software (e.g. Punto Switcher retyping a
word) are no longer remapped by TouchCursor. Everything else is unchanged.

Install over an existing TouchCursor 1.7.1 installation:
 1. Right-click the TouchCursor tray icon -> Exit.
 2. Back up  %APPDATA%\TouchCursor\settings.cfg  (copy it somewhere safe).
 3. Back up the install folder (usually C:\Program Files (x86)\TouchCursor).
 4. Copy ALL files from this package into the install folder, overwriting.
 5. Start TouchCursor again.

To roll back: exit TouchCursor, restore the backed-up install folder.
